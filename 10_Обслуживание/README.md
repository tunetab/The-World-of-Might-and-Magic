Этот каталог хранит технические сведения, не сюжет.

Миграция_v2.json фиксирует исходный Git-коммит, контрольные суммы закрытых глав и сохранённых исторических текстов. Исторические документы проверяются после нормализации переносов строк; закрытые главы — по исходным байтам.

Нормальная работа выполняется средствами PowerShell 7. Python нужен только для сохранённого одноразового сценария миграции. Повторный запуск миграции запрещён её маркером; пересборки выполняются через Завершить_ход.

Обзор устройства: 00_Инструкции_для_ИИ/06_Память_и_связи.md. Проверки новых сценариев: tools/Проверить_систему_v2.ps1.
