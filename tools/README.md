Runtime — PowerShell 7. Все команды ниже — `.ps1` в этой папке. Пользователь пишет обычные сообщения; агент ведёт файлы по [AGENTS.md](../AGENTS.md). Контракт данных и знаний — [Память и связи](../00_Инструкции_для_ИИ/06_Память_и_связи.md).

## Рабочий маршрут

`Начать_ход -Id TURN-... -Title ...` → изменения в возвращённой копии → `Подготовить_ход -Id TURN-...` → `Применить_ход -Id TURN-...`. При прерывании — `Восстановить_ход` с тем же ID: `-Mode resume` продолжает, `-Mode restore` возвращает собственные изменения с проверкой посторонних правок. Порядок сюжетных действий: [Ведение игры](../00_Инструкции_для_ИИ/01_Ведение_игры.md).

После технических правок выполняй `Завершить_ход`. Он собирает граф, индексы, представления реестров, панель, контекст, память и аудит, затем проверяет проект. Каждый генератор запускается один раз; дата неизменного представления не обновляется.

## Чтение

| Команда | Параметры |
| --- | --- |
| Получить_контекст | `-Branch Михаэль`, `-Query капитал`, `-Entity ASSET-0056`; `-MaxWords` по умолчанию 2000; `-Json` включает причины отбора и опущенные блоки |
| Получить_контекст для персонажа | Явная ветка и `-Audience character`; ограничения действуют также в JSON |
| Получить_связи для ведущего | `-Entity ID`, `-Depth` от 1 до 3, `-MaxNodes` от 1 до 200, `-Json`; по умолчанию один переход и 20 соседей; `-IncludeReferences` добавляет упоминания, `-IncludeHistory` — исторические связи |

## Запись и сборка

| Данные | Запись | Представления |
| --- | --- | --- |
| Сообщения | Принять_сообщение, Обработать_входящее | Собрать_индекс_источников |
| Сцены | Сцена_из_входящего, Новая_сцена | Собрать_индекс_сцен, Собрать_связи |
| Персонажи и места | Новый_персонаж, Новая_локация | Собрать_индекс_персонажей, Собрать_индекс_локаций |
| Портреты и активы | Новый_портрет; правила в профильных инструкциях | Собрать_индекс_активов |
| Решения | Новое_решение, Закрыть_решение | Собрать_решения |
| Вопросы | Новый_вопрос, Закрыть_вопрос | Собрать_вопросы |
| Фронты | Новый_фронт, Обновить_фронт | Собрать_фронты |
| Знания | Новое_знание: Text, Truth, EvidenceIds, KnownTo | Собрать_память |
| Положение ветки | Обновить_контекст_ветки: Branch, SceneIds, FactIds, FocusIds, Situation | Собрать_контекст, Собрать_панель_хода |
| Срезы и покрытие | Исходные реестры и карточки | Собрать_срезы_реестров, Собрать_аудит_данных |

Приём по умолчанию создаёт отдельный источник; `-Mode inbox` сохраняет только входящее. `RequestId` отличает сообщения и защищает от повторов.

`-SkipCheck` откладывает проверку. У сборщиков решений и вопросов `-Only` отключает также зависимые сборки; этот режим использует `Завершить_ход`. Команды читают авторитетные JSON. Старый `-ImportFromMarkdown` удалён: потерянный реестр восстанавливают из проверенной копии, не из его представления. Одноразовые миграции в `tools/migrations` не запускаются при обычной работе.

## Поддержка

`Проверить_проект` объединяет проверки структуры, ссылок, реестров, контекста и сохранности истории. Профильные команды: `Проверить_архив`, `Проверить_портреты`, `Проверить_реестры`, `Проверить_контекст`. Сценарные наборы `Проверить_инструменты`, `Проверить_систему_v2`, `Проверить_аудит`, `Проверить_связи` работают на фикстурах и входят в CI. Hooks подключает `Установить_git_hooks`.

`_lib.ps1` загружает шесть библиотек: Core — общие операции; Graph — извлечение привязок; ReadModel — индексы и снимок реестров; Context — отбор, память и пакеты; Connections — навигация и порядок событий; Transactions — безопасная запись. Снимок передают через `-Data` только внутри одной операции чтения и обновляют после записи. Все публичные команды используют общую блокировку проекта.

Мир и карта обслуживаются отдельно: [редактор Regnum](Regnum/README.md), [правила редактора](../00_Инструкции_для_ИИ/07_Редактор_карт.md).
