# Простой режим

---
type: user_quick_mode
status: active
canon_level: support
updated_real_date: 2026-09-22
---

Пользователь присылает сцену, решение, вопрос или идею обычным текстом. Ассистент ведёт файлы по [рабочему циклу](01_Ведение_игры.md). Обсуждение не становится каноном без принятого решения.

Портрет создаётся и сохраняется по [правилам портретов](02_Портреты_персонажей.md). Мир на карте ведётся только по отдельному запросу через [редактор Regnum](07_Редактор_карт.md). Сценовые иллюстрации отключены.
